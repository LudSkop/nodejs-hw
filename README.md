# Node.js HW - 01 Express

This project is a simple Express.js server created as a homework assignment.

## Features
- Express server setup
- Basic routing (`/notes`, `/notes/:noteId`)
- Error handling middleware (500 responses)
- 404 handler for unknown routes
- Environment variables support via dotenv (PORT configuration)
- CORS enabled
- Request logging with pino

## Run project

```bash
npm install
npm start
